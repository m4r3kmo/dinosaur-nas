# Dinosaur NAS

Self-hosted Kubernetes-based retro NAS.

## Hardware

- ASUS X99-E WS/USB 3.1
- Intel Xeon E5-2650 v4
- 32 GB DDR4 ECC
- NVIDIA GTX 1050 Ti
- 2x WD Red 2 TB
- TP-Link Archer TX55E

## Stack

- Debian 13
- K3s
- Helm
- Argo CD
- Jellyfin
- Samba
- Prometheus
- Grafana
- NVIDIA Container Toolkit
- mergerfs
